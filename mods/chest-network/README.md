# Мультихранилище

Сеть соединяет соседние обычные сундуки. Открытие любого из них даёт поиск,
фильтры и сортировку по общей выдаче. У хоста Shift+ЛКМ и Shift+ПКМ по предмету в инвентаре
переносят его в подключённый сундук с подходящим местом. Содержимое хранится в
реальных сундуках игры.

Подключившийся игрок переносит предметы в открытом сундуке обычными кликами
или Shift+ЛКМ. Игра синхронизирует изменение сундука при закрытии. При полном
назначении предмет остаётся в инвентаре. Соседние сундуки доступны для просмотра.
0.0.42 сокращает повторный обход сундуков и вычисление ключей сортировки.
Диагностика обоих игроков записывается в
`%LOCALAPPDATA%/Tinkerlands/chest_network_coop_trace.jsonl`.
Доступ из другого региона мира через отдельный предмет пока в разработке.

Поддерживается сборка Steam 22762534. Установщик проверяет SHA-256 EXE перед
установкой. Для адаптера сохранены исходные идентификаторы мода и уже созданных
предметов. DLL загружается из `mods/native/chest-network/`.

## Сборка

Для DLL релиза использован Rust 1.99.0 и Windows GNU target. Публичная сборка
использует закреплённые проверки ABI и не требует файлов установленной игры.
Из корня репозитория выполните:

```powershell
rustup target add x86_64-pc-windows-gnu
python mods/chest-network/native/build.py
./build.ps1
python tools/package.py
```

`src/` содержит модули GML в порядке, заданном каталогом. `records/` содержит
записи совместимости для тестового терминала из ранних установок. Состав ZIP и
хеши создаёт сборщик релизов. Готовый пакет находится в GitHub Releases.

Референсом раннего исследования был `id5011_shared_storage` автора Antigravity.
Текущая реализация сети написана в проекте Chest Network.
